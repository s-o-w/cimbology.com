## Core Position

Design data must be born as semantically typed graph data grounded in IEC CIM, not trapped inside drawings and tool-native binaries. Every CAD and BIM format in the utility design stack encodes position, not meaning. The engineer's head becomes the integration layer, and when that engineer retires, the integration layer leaves with them.

CIMBOLOGY documents the open semantic architecture, prior art, and reference tooling built to fix that gap: full IEC 61970 and IEC 61968 OWL 2 ontologies, minimal domain extensions, declarative RDF lenses, SHACL validation, and JSON-LD knowledge graphs.
